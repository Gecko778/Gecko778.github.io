2025 秋冬生活记录

Posted on 2025-12-03 In 【生活记录】日记

找工作 ing

2025-12-03

直到今天才差不多搭建好网站布局，当然先是模仿别人，毕竟 hexo 的文档写的一言难尽（评论区有目共睹）。

昨天做了个高中的梦，回味无穷，几乎是笑着醒来的。尝试留住那种幸福感，但我知道随着时间它会被我遗忘，这也是一种无力感吧。

昨天面试了一个南通的公司，比较有意思的是这个面试官问我对于 AI 的看法，自己反而滔滔不绝起来，不提醒我都觉得是我在面试他。聊了大概 44 分钟，他开始总结，说我们公司不轻易招人，还问了我一句“懂我意思吧？”，最后说 HR 后续会联系你。

刚出去走了一圈，还是耳机里面听着周杰伦的《等你下课》。今天刚降温到了零度，楼下的冷风让我见识到的了它的刺骨，冷得我我直哆嗦。林立的大楼挡住了冬日早晨的温暖阳光，留下了一片一片的阴影。走到每天接表妹都会路过的一片草坪，它们贪婪地享受着这钢铁森林所赐予的一片阳光。草坪是一大片黄色，没有生机。

我先是走进一片阴影，因为我本来就在阴影里。听着歌词，回忆起高中的点滴不知不觉就走到了草坪中央。视野变得开阔起来，旁边的别墅群更加立体。旁边的路快修好了，能看见稀稀疏疏的电动车开过。我走进了阳光里。回首看这方形的阴影，正式身后那片大楼的杰作。

回头，我又踏进了阴影里，耳机里的歌曲正结尾。

初踏时，没什么感觉，但是在走下来拖鞋接触水泥平底的瞬间，才意识到它的柔软。

Intro to LLM

by Andrej Karpathy

Phase 1 : LLM Inference

llama-2-70b: powerful, open weights. The weights, architecture, paper are released by Meta. It’s unlike many other large language models you are familiar with. For example, Chatgpt’s architecture is never released. You are only allowed to use the model through the web page but you are not able to access the model.

llama-2-70b is really just two files: parameters file, run.c

parameters are the weights or the parameters of this neural network. It contains 70 billion parameters, every parameter is stored as 2 bytes float 16 numbers as data type.
