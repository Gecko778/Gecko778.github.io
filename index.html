2.1 Flow Model

Two objects:

​ Trajectory is a function of time (0 to 1). time t -> vector Xt

​ Vector Field spatial && time component. (x,t) -> ut(x)

ODE describes conditions on a trajectory with Initial condition X0. We should follow along the vector field which describes direction. When we follow the time vectors across time, directions change over time because the vector field here is time dependent.

Flow is a collection of teajectories that follow ODEs which gather solutions for different initials conditions. We gather them in one function and we call that a Flow.

​ - A vector field defines a ODE in

​ - A trajectory XT is a solution to this ODE.

​ - A flow defines a collection of solutions for that various initial conditions.

Flow model

​ Neural network itself is a vector field

​ Random init

​ ODE

The flow is the map that we implicitly get by simulating this ODE

2.2 Diffusion Model

Stochastic Process Stochastic differential equations are not inherently deterministic like ODEs. Their solutions are not trajectories but random trajectories. Think stochastic process as random trajectory.

Vector Field Like before, with spatial and time component, returns a vector. + Diffusion coefficient which we call Sigma here. Sigma is non negative. If Sigma is 0, we will not inject any noise or randomness; if Sigma is very large, we inject more noise.

Stochastic differential equations (SDEs)

Brownian Motion: random walk continuous space and time

​ Stochastic process W = (Wt) t =0

  1. W0 = 0 Always start at 0
  2. Gaussian increments: Normal distribution, increase linearly in time
  3. Independent increments: random but increasing

Describe an ODE in a form that does not rely on derivatives.

The next time step is the previous time step + h given by to this Vector field + some increment from a brownian motion which is effictive noise, scale by the diffusion coefficient Sigma t. If the sigma t is 0, this is 0. And this is just ODE.

ODE have trajectories as solutions.

SDE have stochastic process, it’s random trajectory.

To define a ODE, we need a vector field.

To define a SDE, we need a vector field + a diffusion coefficient.

ODE is defined by a derivative and an initial condition.

SDE vector field + small noise added from the Brownian motion

Diffusion Model: Convert init distribution(e.g. Gaussian) to data distribution

再比如，要说“我很高兴我有杰克这样一个大学同学”，很多人也会直接翻译：“I’m so glad that I have such a college classmate like Jack”. 这个说法外国人或许听得懂，但就是感觉很Chinglish。英语思维就是描述这个人是谁，描述我们过去在大学都做了什么，从而让大家悟出我们是大学同学这个事实，甚至能联想到你们当年的情形。较为地道的说法是：

He’s Jack, my former classmate. We spent some pleasant time together during college days.

因此，当你说英语的时候，不要立刻想着字对字翻译，想想能否用简单描述的方式来解释，降低语言难度，就像对一个小学生说话一样。
